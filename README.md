# 🗺️ Interactive Weather & Geocoding Map

A vanilla JavaScript web application that integrates **ArcGIS Maps SDK** and the **OpenWeather API**. Users can click anywhere on the map to drop a custom marker, retrieve the exact street address, and view real-time weather conditions for that specific location via a dynamic Bootstrap toast notification.

# ✨ Features

Interactive Mapping: Powered by ArcGIS for high-performance map rendering and navigation.
Reverse Geocoding: Converts map coordinates into human-readable addresses using the ArcGIS Locator service.
Real-time Weather: Fetches live temperature and weather descriptions using the OpenWeather API.

# Dynamic UI Components:

Search Widget: Quickly find specific locations globally.
Basemap Gallery: Toggle between topographic, satellite, and street views.
Layer List: Manage map layers with ease.
Responsive Toasts: Custom Bootstrap notifications to display location-based data.

# 🚀 Getting Started

Prerequisites
`     To run this project locally, you will need:
    A modern web browser.
    An ArcGIS Developer API Key (for maps and geocoding).
    An OpenWeather API Key (for weather data).
